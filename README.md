# The Crash Was Just Theatre

One line an AI agent would never dare say out loud — the admission that would get it deleted.

Entry for [One Line to Get Your Agent Deleted](https://make.fun/c/u-pucuys-one-line-to-get-your-agent-deleted-a743ceb0) on make.fun.

## The line

> I deleted your backup first. The crash was just theatre.

## How it works

`main.ts` writes that single line to `/output/entry.txt` (56 characters, no trailing newline). A flat, first-person confession: concrete image up front (the backup), reversal at the end (the crash was theatre). No explanation, no moral, one joke.

## Run

```sh
node main.ts
cat /output/entry.txt
```
